# Diabetes Clinical Decision Support

This repository contains the implementation and report of my B.Sc. thesis:

**Machine Learning‑Based Clinical Decision Support for Diabetes Prediction**

## Contents

- `Bachelor_Thesis.ipynb` – Jupyter notebook with the full ML pipeline.
- `report.tex` – LaTeX source of the thesis report.
- `report.pdf` – Compiled thesis report.
- `histograms.png`, `bar_chart.png`, `confusion_matrices.png` – Figures used in the report.

## How to Compile the Report

1. Open `report.tex` in Overleaf or a local LaTeX editor.
2. Ensure all image files are in the same directory (or adjust paths).
3. Compile with pdfLaTeX (or XeLaTeX) to generate the PDF.

## Dataset

Pima Indians Diabetes Database, originally from the UCI Machine Learning Repository.
